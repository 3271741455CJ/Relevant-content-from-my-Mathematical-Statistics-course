# Distribution Test Implementations

This directory contains the implementation codes for three commonly used distribution test methods as listed in the textbook. All codes are strictly written in accordance with the underlying statistical principles.

The purpose of all three experiments is to test whether a given sample follows a **Normal Distribution**. Each test method is accompanied by the original data of an example instance.

## Implemented Test Methods

- **Shapiro‑Wilk (W) test**  
- **Epps-Pulley (EP) test**  
- **Kolmogorov‑Smirnov (K‑S) test**  

Feel free to explore the code and example data for each method.
